# 历史 H1-Sup 与本次复训的协议比较

历史基准为 `/data2/mzy/GAD/CAFE_codebase/outputs/heatmap/summaries/full_seed1_b0_h1sup_20261014_run1/README.md` 对应的原始运行；本次为 `h1_sup_center_lr1_noclip_seed1`。本次截至 VAL epoch 15，仍在训练。

| 项目 | 历史完整 H1-Sup | 本次 H1-Sup |
|---|---|---|
| TRAIN 时间采帧 | 每个时间段随机抽一帧，每次访问可变化；`random_sampling=false` 在该数据集仍走随机分段采样 | `fixed_center_train=true`，每段固定中心帧 |
| 并行 | 2 卡 DataParallel，每卡 8 clips | 4 卡 DDP，每 rank 4 clips |
| BatchNorm | ResNet18 普通 BatchNorm，局部批次约 8×5=40 帧 | 普通 BatchNorm，无 SyncBatchNorm，局部批次约 4×5=20 帧 |
| H1 热图损失归一化 | 对聚合后的全局 batch 中 matched groups 求平均 | 每 rank 对自己的 matched groups 求平均，再由 DDP 等权平均四个 rank 的梯度；各 rank matched group 数不同则权重不同 |
| TRAIN 样本顺序 | DataLoader 随机采样 | DistributedSampler 分片/洗牌；seed 相同不代表同一步样本相同 |
| VAL 评价 | 旧评价器的置信度排序存在单元素 set 问题；原运行用它选择 epoch 21 | 修正排序并限定 VAL clip 清单，按每轮 mAP@1.0 选模；四卡分片合并预测 |
| VAL batch | 1 | 每 rank 4 |

相同项：TRAIN 6,444 / VAL 1,386、ResNet18、T=5、12 group slots、H1-Sup 高斯 sigma ratio 0.15、原 embedding membership 与 B0 Hungarian matcher、有效 batch 16、FP32、Adam、weight decay 0、head/backbone LR 都为 1e-5→1e-4、5 epoch warmup、线性衰减、30 epochs、402 更新/epoch、seed 1、无梯度裁剪、每轮 VAL 选模。当前 `models/heatmap.py`、`models/heatmap_criterion.py`、`models/__init__.py`、`util/group_export.py`、`models/group_matcher.py` 与历史原始运行的源码快照 SHA256 完全相同；H1 不执行新增的 SAM 分支。

历史 README 的原评价器所选结果为：B0 14.2053，H1-Sup 18.4665，H1 增益 +4.2612 mAP@1.0 点。历史保存的**已选权重预测**后来用当前修正评价器在同一 1,386 VAL clips 上复评：B0 18.27，H1-Sup 22.95，H1 仍领先约 4.68 点；这没有按修正评价器重新搜索历史全部 30 个 epoch。本次截至 epoch 15：B0 已完成 epoch 中最佳为 20.8631（epoch 15），H1-Sup 为 10.3981（epoch 5），差距 -10.4650 点。当前最终 30 轮结果尚未产生。

因此，旧版评价器能改变绝对数值和最佳 epoch，但不能单独解释 H1/B0 的相对排名翻转。固定中心帧消除了时间抖动，H1 的空间辅助监督可能更易记住训练帧；较小的局部 BatchNorm 批次和 DDP 的 matched-group 归一化也改变优化过程。这些都是**候选解释**，现有一次训练不能量化各自贡献。要复现历史收益，需分别控制采帧与并行/损失归一化，而不能仅恢复学习率。
